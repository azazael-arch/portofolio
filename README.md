Sebuah website portofolio interaktif dengan estetika **Cinematic Dark Fantasy**, menggabungkan animasi canvas partikel, dukungan dual bahasa (ID/EN), galeri foto interaktif dengan viewer lightbox, serta showcase proyek korporat dan karya multimedia.

## ✨ Fitur Utama

- 🎨 **Cinematic Dark Aesthetic**: Desain gelap premium dengan aksen Crimson Ebers (`#e63946`), Gold Ember (`#ff6b35`), dan Glassmorphism.
- 🌌 **Interactive Particle System**: Animasi Canvas HTML5 untuk partikel dan lintasan garis optik bergerak secara real-time.
- 🌐 **Dual Language (ID / EN)**: Switcher bahasa serentak dengan penyimpanan preferensi di `localStorage`.
- 🖼️ **Photo Gallery & Lightbox Viewer**: Galeri foto 6-grid interaktif lengkap dengan modal viewer fullscreen yang mendukung navigasi keyboard (`Esc`, `←`, `→`).
- 📊 **RPG Skill Sheet & Counter**: Animasi progress bar keahlian teknis dan angka statistik interaktif dengan *IntersectionObserver*.
- 🎯 **3D Floating Card Tilt**: Efek paralaks 3D pada kartu hero dan banner proyek saat disorot kursor.
- 🖱️ **Custom Dual Cursor**: Pointer kursor khusus dengan dot inner dan ring follower responsif.
- 📱 **Fully Responsive Layout**: Optimal di semua layar (Desktop, Tablet, Mobile) dengan menu navigasi hamburger sinematik.

---

## 🛠️ Teknologi & Berkas Utama

- **HTML5**: Struktur semantik dengan Open Graph SEO meta tags.
- **CSS3**: Vanilla CSS modern (*Custom Properties/Variables*, *Flexbox*, *CSS Grid*, *Glassmorphism*, *Keyframe Animations*).
- **JavaScript (ES6+)**: Custom Canvas particle system, i18n engine, modal lightbox, & event listeners.
- **Libraries**:
  - [Lucide Icons](https://lucide.dev/) (Ikon vektor modern)
  - [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) (Animasi entrance scroll)

## 💻 Cara Menjalankan Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/azazael-arch/portofolio.git
   ```
2. **Masuk ke direktori proyek**:
   ```bash
   cd portofolio
   ```
3. **Buka `index.html`**:
   - Anda dapat membuka berkas `index.html` secara langsung di peramban (browser), atau menggunakan ekstensinya seperti **Live Server** di Visual Studio Code.
